# Ziva Backtesting

Ziva Backtesting — free historical replay & backtesting app for gold and forex traders, by Ziva FX.

## About

Ziva Backtesting is an offline backtesting and historical replay app for Android. It covers 9 instruments: 7 major forex pairs, plus gold and silver. It uses Dukascopy historical data.

Current version: 2.6.4
